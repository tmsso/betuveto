# ant-on-cube

Interactive cube wireframe exercise for steering an ant using Left/Right/Back decisions.

## Run locally

```bash
npm install
npm run dev
```

## Controls

- Buttons: **L**, **R**, **B**
- Keyboard: `L`, `R`, `B`
- **Reset** stores the current run in a 5-slot LIFO history (excluding pinned slots), then resets the ant.

## Deploy on Vercel

This is a standard Next.js app and can be deployed directly on Vercel.
