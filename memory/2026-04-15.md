## Ant on Cube debugging session
**Date:** 2026-04-15 01:17–01:20  
**Location:** GitHub repository `tmsso/ant-on-cube`

### Problem Summary
After hardening the code to prevent "TypeError: undefined is not iterable" during Next.js SSG/prerendering (for Vercel deployment), the ant became immobile. The defensive guards were too aggressive, causing:
- `getTurnNode` failing to find valid neighbor nodes due to floating‑point comparison (`0` vs `0.0`)
- Incorrect axis‑sign mapping in `calculateRelativeTurns`, leading to `-1` (invalid) left/right nodes

### Root Causes Identified
1. **Floating‑point equality** – `BASE_VERTICES[i][0] === targetCoords[0]` fails because `targetCoords` are integers but represented as floats after arithmetic.
2. **Axis‑cycle rule** – The previous `turnAxisCycle = [[1,2],[2,0],[0,1]]` assumed positive direction signs only; negative direction vectors broke the mapping.
3. **Overly defensive `displayChars` fallback** – `formatPath` could still receive `undefined` during the prerender phase, causing downstream crashes.

### Solution Applied
- **Robust node lookup**: Replace `===` with `Math.abs(a - b) < 0.1` tolerance check in `getTurnNode`.
- **Adaptive axis‑finding**: Rewrite `calculateRelativeTurns` to iterate `(+1, -1)` on the orthogonal axes until a valid adjacent node is found.
- **SSG‑safe conditional rendering**: Keep `(logicPath || []).map` and `(slots || []).map` guards, but ensure they don't block valid turn mappings.

### Outcome
- Build now passes (Vercel deployment successful).
- Ant movement restored; L/R/B buttons and keyboard controls work.

### Key Technical Learnings
- **Next.js SSG builds** run `useMemo` and render components in a Node environment where `window` isn't defined, but `TRANSLATIONS` and `BASE_VERTICES` are.
- **Floating‑point coordinates** must be compared with epsilon tolerance when dealing with integer‑based 3D geometry.
- **Cube adjacency logic** must account for both + and − directions along orthogonal axes; a simple cyclic rule fails for negative approach vectors.
