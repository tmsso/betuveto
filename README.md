# Betuveto - Hungarian Word Game

Modern word puzzle game built with:
- React 22 + Vite 6
- Tailwind CSS 4
- OpenClaw AI integration

## New Features (2026 Q2)
🎇 **Dynamic Visual Feedback**  
Confetti explosions for big discoveries  
📱 **Mobile-Optimized UI**  
Fluid grid layouts & touch interactions  
⌨️ **Keyboard Navigation**  
Full keyboard control system
